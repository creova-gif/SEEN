# User stories (with acceptance criteria)

| ID | As a… | I want… | Acceptance criteria | Status |
|---|---|---|---|---|
| US-01 | viewer | to browse creators | Explore › Creators lists every creator with ≥1 public story; each card opens a profile; loading/error/offline states shown | ✅ |
| US-02 | viewer | to follow a creator | Follow toggles instantly, persists across reloads, rolls back on failure, appears in Profile › Following | ✅ |
| US-03 | viewer | to browse and save collections | Thematic and institutional filters; save persists; detail lists only stories that exist | ✅ |
| US-04 | creator | to see open funding | Real listings with official links and sources; sorted by deadline; rolling/upcoming/unannounced intakes shown honestly | ✅ |
| US-05 | creator | to track an application | Save → checklist with progress; applied only when complete; closed calls not trackable | ✅ |
| US-06 | any user | notifications | Unread badge in header; open marks read and navigates; mark all read | ✅ |
| US-07 | any user | the back button to work | Browser back returns to previous screen; deep links open the right screen after sign-in | ✅ |
| US-08 | any user | to never hit a blank screen | Crashes show a recoverable error with reference id | ✅ |
| US-09 | admin | only admins in admin tools | Other roles see Restricted state | ✅ (UI); server enforcement pending |
| US-10 | person signing up | not to be able to self-grant moderation | Moderator choice becomes a request | ✅ |
| US-11 | keyboard / screen-reader user | to operate every new screen | Tabs arrow-key navigable; all icon buttons labelled; axe AA clean on 11 screens | ✅ |
| US-12 | viewer | one place for everything I saved | Library "Saved" tab | ⏳ |
| US-13 | creator | real funding listings with apply links | 12 researched listings, each linked to the funder and dated | ✅ |
