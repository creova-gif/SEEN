# Archive

Material that predates the September 2026 product reconciliation
(`docs/audit/BASELINE.md`). Kept for history and for the content-production
material it contains (narration scripts, voice-actor briefs, season outlines).

**Do not treat status claims in here as current.** Several documents describe
the product as "complete", "production ready" or "launch ready"; the 2026-09
audit found crashes, dead navigation and fake metrics that contradict those
claims. The current state of the product is in `docs/release/RELEASE_READINESS.md`.

- `legacy-docs/` — the previous contents of `docs/`
- `legacy-root/` — status reports that used to sit in the repository root
- `../../archive/src/` — source modules that were unreachable from the app
  (see `docs/audit/CODEBASE_AUDIT.md` for the list and why they were archived)
